Published Webflow config still contains events e-395/e-396 and e-650/e-651 targeting .partner_logos, with action lists a-45/a-46/a-90/a-91 targeting obsolete child .tooltip2_tooltip-wrapper. The current component has no such child, but the class events could still bind. Moving the native component to tdb-partner-logo detaches these events without a runtime observer or interception.

The IX2 definitions remain in the Webflow project/bundle. The supported API exposes IX3, not IX2 deletion. Do not delete shared a-45/a-46 blindly: they also have partner_logos-2 and other legacy event references. Retiring the stored definitions requires a separate Designer/sitewide usage audit.
