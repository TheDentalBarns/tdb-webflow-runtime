# Ivory treatment guide

The Treatments collection has a native `Treatment Guide — wheel` component below the existing guide. The old guide remains available for comparison. The native component owns the heading, CMS introduction, chapter labels, typography, dividers and source content. The approved Ivory iteration remains an explicitly authorised temporary patch. It replaces the cream/charcoal comparison with one bordered card. Designer and the initial unenhanced page retain the original thin-orbit layout until native migration.

The treatment name, introduction, chapter titles and full chapter bodies use existing CMS bindings. Five short introductions are shared component properties: the Treatment collection is at its 60-field limit. No collection fields or treatment content were changed. The title remains an editable component property. No content is fetched or replaced by JavaScript.

## Ownership and loading

- `src/runtime/treatment-guide-loader.js` is a small presence/consent gate. It prepares the wheel near the section and replays an initial drag after preparation. Native Webflow tabs and native details provide navigation and full chapter content when an enhancement fails.
- `src/treatment-guide/wheel.js` owns pointer/keyboard motion. Five equal sectors have a complete first segment centred at twelve o'clock, with boundaries offset by 36 degrees. The inner aperture is 28% of the outer diameter. There is no separate marker. The selected whole sector uses the deeper cream token. Grabbing eases its opacity towards the light pad while soft radial-gradient pressure shading follows the finger, clipped inside the annulus. Release preserves the existing angular/radial spring and momentum; pressure fades out and the selected sector darkens smoothly. Unwrapped angles cross twelve without jumping. Work stops when settled, offscreen, hidden or destroyed. The wheel is the keyboard slider; its centre and corners remain available to page scrolling. Direct gestures, arrows, keyboard selection and Learn more invoke the existing slider focus lifetime to move the site bars away.
- `src/treatment-guide/card.js` creates one temporary preview from the bound panes. The existing pagination ticker moves into the wheel centre, replacing the large numeral and label. Pagination, two footer arrows and the usual black Learn more button retain their DOM nodes across all five chapters. A second `TDBNativeTicker` rolls the small chapter artwork inside Learn more. The label stays still. Titles slide horizontally; blurbs use shared fade timing, with all rows reserving their maximum height. Learn more always opens the current chapter. The only section arrows sit at the right of the same footer row. On desktop, the divider and content panel match the measured wheel height; mobile retains a horizontal divider.
- `src/treatment-guide/drawer.js` is prepared on Learn more intent. It reuses USP styles, shared drawer, ticker, Swiper, reading-state and controls. The header uses equal text styles and equal-width columns around a truly centred rule. A fixed 14rem introduction area follows the review drawer's icon/rule/excerpt geometry. Its text fades while the chapter body moves. `TDBNativeTicker` renders the large diamond, thumbprint, lotus, quotation marks and barn-window assets. Large drawer artwork is warmed only on drawer intent. Chapter changes update the originating wheel, centre pagination and small CTA icon beneath the drawer.
- `tdb-treatment-guide.css` contains the temporary scoped ring/card patch and established drawer differences. It loads near the guide, before wheel mounting; no guide layout is added to shared initial CSS. If the enhancement fails, native tabs/details remain visible. If the drawer fails after the preview mounts, the selected native full body is revealed and focused.
- The shared drawer's default focus behavior is unchanged. The guide returns focus to the persistent Learn more control (or the active native chapter's control in fallback mode).

## Validation and limits

Automated Chrome checks cover desktop, 390px and 320px layouts, all five tabs, stable preview height, native content when both guide modules are blocked, keyboard selection, spring intermediate frames, touch dragging beyond the orbit, colour interpolation, drawer selection, focus return, close, inner scrolling and phone landscape. Physical iPhone Safari remains untested. Desktop backgrounds are inert while the modal is open; the wheel continues to reflect drawer selection visually.

The guide tests cover elastic release, annulus-only hit testing, crossing twelve, keyboard/native selection, intermediate sector shades, re-grab lightening, pressure fade, filled-sector/card synchronisation during a held drag, five-sector geometry and teardown. Shared ticker tests cover interrupted artwork changes. Browser checks cover desktop/mobile geometry, stable controls, both actual tickers, footer arrows, all five small CTA icons, mouse/touch gestures, drawer synchronisation, focus return and native fallback. Build artifacts and release inventory must be checked together. The existing unrelated `src/smile-gallery/feed.js` formatting warning remains outside this change. Changed source files pass formatting checks.

The refined press state keeps the active whole sector visible at 72% of the selected tint while held, easing between sectors as the card changes before release. Pressure shading uses the same deeper cream with an 8% ink blend only at its soft centre. Five faint, upright chapter icons reuse the CTA artwork and brighten with each sector's interpolated fill. Supporting card copy uses the native neutral tone. On mobile, the circle's top, side and bottom spacing all use the page's 5vw gutter. The drawer's fixed introduction now contains the review-style orange-2 panel inside an orange-1 surround; its reserved height includes the surrounding space in portrait and returns to document flow in phone landscape.

Ivory uses the existing `--base-color-brand--orange-1` (#f9f2e6), `--base-color-brand--orange-2` (#ebe2d2), `--base-color-brand--orange-3` (#d6cab4) and brand black tokens. Typography remains native Sweet Sans. The CTA uses the established small diamond, lotus and barn masters and the existing 24-unit quotation mark. `assets/treatment-guide/tdb-thumbprint-small-1px.svg` derives a small optical version by retaining seven widely spaced original brand ridges and strengthening their screen stroke. The original large drawer thumbprint is unchanged. Small artwork is warmed near the guide, not on the homepage.

The native five full bodies count toward initial page HTML, including closed details. The temporary old/new comparison intentionally duplicates that content. Drawer copies and Swiper loop copies are deferred until intent. The wheel adds shared motion/ticker requests only when not already loaded; drawer dependencies are likewise deduplicated by `TDBModules`. File/gzip estimates are asset budgets, not measured TBT or browser transfer totals.

The click-wheel patch adds one small card controller to the existing wheel bundle and loads the scoped stylesheet near the section. Exact raw/gzip sizes and source lists are recorded in `config/build-artifacts.json`; existing shared downloads reduce the cold path. Native page CSS and HTML are separate Webflow output. No new global startup request or homepage guide request is introduced.

From the Designer perspective, bindings and resting layout remain editable. From the visitor perspective, content and controls remain useful through loading failure. From the runtime perspective, physics and drawer construction have separate lifecycles and gates. From the release perspective, all four install references move to one immutable commit, with a staging-only publish.
