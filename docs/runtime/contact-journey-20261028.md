# Shared contact and journey planner

The shared Contact us definition owns the contact links, native journey form, reserved result space and map frame. Home has no instance and gains no DOM. Six decorative icon embeds and wrappers have been removed; pseudo-element masks reuse canonical Webflow SVG Assets (including the existing footer Instagram/Facebook artwork). The mobile link now has a working `tel:+447488893573` destination.

The former Elfsight embed contained only its widget ID. It is replaced by an in-page Google Maps and Routes enhancement. Native GET form submission and the separate directions link remain useful without JavaScript. Google code is conditional on proximity and functional consent. A deliberate submit requests one traffic-unaware driving route with only path, duration and distance. Origin text is kept only in the form/current memory; this module writes no storage or analytics. Failed requests retain the external directions link. Consent withdrawal removes map/route DOM and invalidates pending results; it cannot recall already transmitted requests.

## Ownership

- Designer: shared structure, responsive layout, headings, form, reserved map/result geometry and colours linked to existing site variables. No inline JS/CSS patch.
- `src/runtime/journey-loader.js`: shared registry, proximity, deferred CSS and first-submit capture/replay.
- `src/journey/journey.js`: consent, one SDK flight, map and route lifecycle, validation/error messages, stale-result suppression, repeated-search deduplication and numeric result sequencing.
- `src/shared/native-ticker.js` and `TDBMotion`: the existing announcement-banner ticker owns every numeric roll. The journey module only supplies successive values. After a shared ticker-length hold, minutes decrement by one and distance by 0.1 mile; each step has a short rest at 1.25 times the central ticker duration. The initial lead is approximately ten percent, bounded at eight steps for long routes. Icons and units do not move. Actual results are announced immediately to assistive technology. Reduced motion, hidden/offscreen results, new input and consent withdrawal bypass or cancel decorative staging.
- `src/runtime/lazy-icon-masks.js`: existing proximity observer releases the six contact masks and three journey assets. Instagram/Facebook reuse the exact footer artwork; the clock and external-link globe reuse existing shared Assets. The distance glyph is one new canonical SVG Asset. Designer reserves these spaces; lazy decorative artwork is absent in Designer/no-JS, as already disclosed and consistent with the footer.
- `src/styles/tdb-journey.css`: enhancement/focus states only. No independent motion.
- Google Cloud project `tdb-reviews-509711`: website-restricted staging browser key, scoped to Maps JavaScript API and Routes API. Key value is stored on the shared native journey root, not in this repository.
- Map ID `a89b9d7c9a869537d58a7d2a`; style ID `abdd84917bc4e7b4c1e9ff6b`. The single cloud style is shared by all instances. `config/journey-map-style.json` records the existing cream/sand/neutral palette used by that style. Google cloud styling cannot reference CSS variables: if the brand palette changes, update this central style as well. Marker and route colours read the native CSS variables directly.

Map centre verified against the existing business Google Maps link: 52.6300414, -1.8014216. Routing uses the full business address so Google resolves the access point rather than routing to an arbitrary point on the building.

## Native design and fallback

The shared native component contains the shorter heading "A little closer to calm", postcode/town form, two fixed metric cells, explanatory note, native secondary button and map frame. Numeric slots start at `00` and `00.0`; `min` and `miles` are separate stationary native labels. The result grid is reserved before any request. The "Open in Google Maps" link uses the existing `button is-secondary` class pair, a native globe mask holder, a new-tab label and `noopener noreferrer`. Its previous one-off link style is removed. No runtime layout patch compensates for Designer. The connector applies the native styles directly; a fresh visual Designer session was unavailable after sign-out, so only native tree/export and published geometry are verified in this final pass.

All authored colours reference existing cream, sand, charcoal and white variables. The map border/divider is vertical on desktop and horizontal on mobile. The mobile map is portrait. Roadmap/Terrain selection uses Google's own map control. Both route-request and map-loading feedback use the usual shared masked spinner and central motion profile; no grey busy-opacity state remains. Google owns its own controls, tiles and geographic colours. The cloud map palette remains the documented central exception to live CSS-variable binding.

Without the enhancement, native copy and placeholders remain readable, the GET form opens the Google Maps route and the secondary button provides directions. Before functional consent the map remains a native placeholder; an explicit search invites consent and is replayed after acceptance. Google's SDK callback, rather than script transport alone, establishes API readiness. Authentication failure, transport failure and route failure leave a useful fallback. No billing or financial account was changed. Budget alerts/hard quota caps were not configured during this work; production activation is separate.
